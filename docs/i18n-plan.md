## 作り方
1. **文言を1か所に集める**：`shared/i18n.js` に `t("home.countdown")` のような呼び出しと、日本語・英語の辞書を置く。まず日本語だけで置き換えて、見た目が変わらないことを `npm run test:smoke` で確かめる。
2. **言語の選び方**：最初はブラウザの言語（`navigator.language`）。設定の「その他」で切り替えられるようにし、選んだ言語はブラウザに保存する。
3. **日付・お金の表示**：`Intl.DateTimeFormat`・`Intl.NumberFormat` を使い、言語に合わせる（英語では「Dec 4 (Fri)」「¥32,000」など）。
4. **都市・空港の名前**：時差や地図に使う表（GEO・TZ_WORDS・AIRPORTS）に英語名も足す。Google の場所の候補は `language` を切り替える。
5. **フレーズ集**：今は「日本語 → 現地の言葉」。英語の利用者には「英語 → 現地の言葉」が必要で、元データを作り直すことになるので、英語版の最初は外してもよい。
6. **アフィリエイト**：言語ごとに紹介先を選ぶ（メモリー「Trunk. の多言語化予定」参照）。A8 の KKday・アゴダ遊び体験は日本語ページ・日本円のみなので、英語では Klook（Travelpayouts）を使う。アゴダは英語の都市ページ（/en-us/city/…）。Omio は omio.com の区間ページ。
7. **LP など**：`/en/` の下に英語版を置き、`hreflang` でつなぐ。記事は需要を見て少しずつ。

## お金・法律まわり
- 海外への販売は、国ごとの税の手続きが重い。始めるときは Stripe Tax か、税の処理まで代行する Paddle・Lemon Squeezy を検討する（計画書の方針どおり）。
- 英語のプライバシーポリシーと、販売するなら英語の特商法に当たる表示（返金の決まりなど）が必要。

## 順番の目安
